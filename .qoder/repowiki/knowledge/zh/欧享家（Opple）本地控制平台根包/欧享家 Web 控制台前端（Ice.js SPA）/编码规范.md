- 所有 HTTP 请求统一通过模块级 `api(path, init?)` 封装，自动设置 `Content-Type: application/json` 并在非 ok 或返回 `j.error` 时抛错。
- 设备位置用联合类型 `Pos = CirclePos | SegmentPos | PointPos` 表达，并通过 `kindOf` / `isCeiling` / `isStrip` 等判别函数区分吸顶灯、灯带、网关三类设备。
- 坐标系统一使用 0-100 百分比表示平面位置，配合 `UNIT=0.05` 换算成米（`toM`），3D 与 2D 视图均基于此比例映射。
- SVG 图标以独立的 `Glyph*` 函数组件定义，使用 `currentColor` 继承容器颜色，并通过 `aria-hidden` 标记装饰性图形。
- 样式采用 CSS Modules，组件通过 `styles.xxx` 访问类名，避免全局样式污染。

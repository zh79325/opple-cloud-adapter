根 `package.json` 通过 `opple` 与 `web` 两个脚本分别启动 `cli_tool` 子模块的 `bin/opple.js` 终端入口和 `web_dashboard` 子模块的轻量 http 后端（`src/opple/server.js`），两者共同依赖 `src/opple/client.js` 中的 OppleClient 完成云端鉴权、token/projectcode 管理与接口封装；数据层以 `data/local-tree.json` 作为持久化快照，CLI 写入后 Web 端优先读取、无快照时回源云端并落盘，从而保证命令行与可视化控制台的数据一致性。Node ≥22 为两个子模块的共同运行环境。

- CLI 命令以字符串分支（`if (cmd === 'xxx')`）在单一 `run(argv)` 函数内集中分发，每个子命令内部再按参数做校验与错误抛出。
- 对外部配置（token/projectCode）优先从 `process.env.OPPLE_*` 读取，回退到 `OppleClient.loadConfig()` 加载 `~/.opple-cli.json`，形成统一的环境覆盖策略。
- 所有对欧享家云端的请求统一走 `OppleClient.request`，并在其中校验 `StatusCode !== 0` 后抛出带 `[code] Message (path)` 格式的错误。
- 设备控制指令通过十六进制 `msgType`（如 `0x03130000`）+ 逗号拼接的 values 数组下发，CLI 层将人类可读操作（on/off/bright/color/daylight/scene）映射为这些底层常量。

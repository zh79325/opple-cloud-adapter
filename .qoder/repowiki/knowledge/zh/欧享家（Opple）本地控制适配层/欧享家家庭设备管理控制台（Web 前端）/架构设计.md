单页面应用，入口为 `src/pages/index.tsx`，通过 Ice.js 约定式路由注册到 `/`（见 `.ice/routes-config.ts`）。应用配置在 `src/app.ts` 使用 `defineAppConfig`，构建配置在 `ice.config.mts` 中启用 ESM server 与开发代理 `/api → http://localhost:5170`。UI 全部集中在一个巨型组件文件内：顶层 `IndexPage` 维护家庭树与视图状态（home / room），子组件按职责拆分——`HomeView` 展示统计与房间卡片、`RoomScene3D` 用 CSS 3D transform 渲染房间盒子与设备、`RoomEditor` 基于 SVG 实现二维拖拽布局编辑器、`DeviceList` 列出房间设备。样式采用 CSS Modules（`index.module.css`），图标以内联 SVG 函数组件（`Glyph*`）呈现。所有后端交互统一经模块级 `api()` 函数调用 `/api/*`，由 Ice dev server 代理到本地 Node 后端；生产环境则直接请求远端 API。

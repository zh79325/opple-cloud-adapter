单页应用，入口由 Ice.js 约定式路由解析 `src/pages/index.tsx` 挂载到 `/`，应用配置通过 `src/app.ts` 的 `defineAppConfig` 注入。
- 构建与运行时：`ice.config.mts` 使用 `@ice/app` v3，启用 ESM server (`server.format: 'esm'`)、按需加载 (`onDemand: true`)，生产环境走 swc minify；webpack 钩子中固定 devServer 端口为 3000，并通过 `setupMiddlewares` 将 `/api/*` 请求动态 `import()` 进 `../src/opple/server.js` 的 `handleRequest`，实现页面与 API 共用同一 dev server。
- 前端代码组织：`src/pages/` 下仅一个首页组件，样式采用 CSS Modules（`index.module.css`），全局样式在 `global.css`，图标以独立 Glyph* 函数组件内联 SVG。
- 数据层：所有 HTTP 请求统一经模块级 `api()` 封装调用 `/api/*`，由 Ice dev server 中间件转发至本地 Node 后端；生产环境直接请求远端 API。
- 依赖方向：web 层仅依赖 `@ice/runtime`、`react`、`three`，业务逻辑集中在单一巨型组件文件内（HomeView / RoomScene3D / RoomEditor / DeviceList 等子组件）。

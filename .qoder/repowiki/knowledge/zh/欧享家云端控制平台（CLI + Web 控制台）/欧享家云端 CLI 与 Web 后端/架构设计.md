模块由两条入口组成：`bin/opple.js` 作为 CLI 可执行文件，仅做 `run(process.argv.slice(2))` 的薄包装；业务逻辑集中在 `src/cli.js`，按命令字（token/homes/tree/devices/actions/light/scene/call/raw）分支分发到 `src/opple/client.js` 暴露的 `OppleClient` 方法。

- `src/opple/client.js`：零依赖 HTTP 客户端，封装鉴权头（`headers()`）、通用 `request/get/post`、以及 `/api/*` 业务接口（checkToken、homeList、tree、roomDevices、actionAbility、callAction），凭据通过 `~/.opple-cli.json` 或 `OPPLE_TOKEN`/`OPPLE_PROJECTCODE` 环境变量注入。
- `src/opple/server.js`：基于原生 `node:http` 的 REST 服务，复用 `OppleClient` 暴露 `/api/homes|tree|sync|devices|summary|actions|positions`，同时托管 `web/build` 静态资源；使用 `data/local-tree.json` 缓存家庭/房间/设备快照，`data/device-positions.json` 持久化房间布局与设备位置。
- 依赖方向单向：CLI → client；server → client；client 不反向依赖上层。
